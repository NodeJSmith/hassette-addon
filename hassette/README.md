# Hassette

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]

Async, type-safe Python automations for Home Assistant.

[Hassette](https://github.com/NodeJSmith/hassette) runs automations written as typed Python apps, with a
web UI for watching what they do. This add-on connects it to Home Assistant automatically and serves the UI
in the sidebar.

See the **Documentation** tab for setup.
