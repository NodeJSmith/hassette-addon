# Hassette add-on for Home Assistant

Home Assistant add-on repository for [Hassette](https://github.com/NodeJSmith/hassette), async, type-safe
Python automations for Home Assistant.

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FNodeJSmith%2Fhassette-addon)

Or add `https://github.com/NodeJSmith/hassette-addon` under **Settings → Apps → App store → ⋮ →
Repositories**.

## Add-ons

| Add-on | Description |
|---|---|
| [Hassette](hassette/) | Runs hassette next to Home Assistant, with its web UI in the sidebar. |

Not installable yet: the add-on image ships with the first release in the hassette
[HA Add-on v0.1 milestone](https://github.com/NodeJSmith/hassette/milestone/15).

Versions follow hassette releases. hassette's release workflow updates `hassette/config.yaml` and the
changelog here; don't bump them by hand.
